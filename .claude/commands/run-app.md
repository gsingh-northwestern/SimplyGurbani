# Build and Run

1. List available simulators: `mcp__xcodebuildmcp__list_simulators`
2. Boot iPhone 15 if needed: `mcp__xcodebuildmcp__boot_simulator`
3. Build the app: `mcp__xcodebuildmcp__build_sim_name_proj`
4. Install on simulator: `mcp__xcodebuildmcp__install_app`
5. Launch the app: `mcp__xcodebuildmcp__launch_app`
6. Capture logs if needed: `mcp__xcodebuildmcp__capture_logs`
